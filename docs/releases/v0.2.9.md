# Hop v0.2.9

[简体中文](v0.2.9.zh-CN.md) | **English**

v0.2.9 converges the Hop `v0.2` line around personal developers, Multi-VPS operators, and Cursor / VS Code Remote-SSH workflows, pairing `hop-rs`, `hop-rs-frontend`, and `luci-app-hop` at `v0.2.9`.

## Highlights

- **Zero-Agent Protocol & Latency Probing (`asset_health`)**: Surfaces stored connection health and RTT latency across the Catalog, Control API (`POST /api/v1/assets/probe`, `POST /api/v1/assets/{id}/probe`), CLI (`hop-server asset probe`), SSH TUI (`r` shortcut), and Web Panel. SSH probes verify RFC 4253 `SSH-` banners without requiring target agents.
- **End-to-End Audit Trail (`audit_events`)**: Records mutations across Control API and local CLI commands, exposes `GET /api/v1/audit-events` and `hop-server audit list`, and prunes aged records automatically at startup and every 6 hours.
- **Multi-VPS & Remote-IDE Ergonomics**: Adds `hop-server ssh-config` (`--mode relay` and `--mode proxyjump`), declarative `tags` in `hop.yaml`, editable `display_name`, `--credential <id_or_name>` resolution, and a redesigned Web Panel workbench.
- **Security & Protocol Tightening**: Enforces exact port matching on `.hop` `ProxyJump` targets, forwards client PTY `TERM`, populates `key_id`/`asset_id` on runtime sessions, removes remote HTTP manifest routes (`/api/v1/config/*`), and publishes multi-arch (`linux/amd64`, `linux/arm64`) container images.

## Upgrade

- No SQLite migration is required from `v0.2.8`.
- Back up `hop.yaml` and `data_dir` (`hop.db`, `hop.secret`, `hop_host_key`), then update `HOP_VERSION=v0.2.9` across `hop-rs`, `hop-rs-frontend`, and `luci-app-hop`.
