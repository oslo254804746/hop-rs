# Hop v0.2.5

**简体中文** | [English](v0.2.5.md)

发布于 2026-08-25。

v0.2.5 是 SSH 互操作性与安全维护版本。不包含 SQLite 迁移、配置格式变更或面板功能变更。

## 修复内容

iOS 上的 Termius 可能会在 SSH `first_kex_packet_follows` 字段中，针对服务端不支持的密钥交换算法发送猜测数据包。SSH 协议要求在猜测错误时忽略这个数据包；旧版 russh 可能把它当成下一条消息解析，并报错：

```text
SshEncoding: character encoding invalid
```

Hop 现使用 russh 0.63.1，其中包含上游修复及对应的未知 KEX 猜测回归测试。修复位于 SSH KEXINIT 协议层，不是交互终端或 UTF-8 设置问题。现有 OpenSSH、密钥、PTY、exec、SCP/SFTP、ProxyJump 和 TCP 转发行为保持支持。

## 安全与依赖升级

russh 从 0.61.1 升级到精确锁定的 0.63.1。除 KEX 兼容性修复外，该版本还包含上游安全修复：在调用客户端 Handler 回调前校验服务端提供的通道 ID，并阻止不带 MAC 的 MAC 强制型分组密码协商导致进程 panic。

## 兼容性与升级

- 不新增 SQLite 迁移，也不改变数据库格式。
- 不新增、删除或自动改写配置项。
- 停止 Hop，备份持久化数据与配置，将 Compose 部署设置为 `HOP_VERSION=v0.2.5` 后启动。重启后验证一次 Termius iOS 连接和一次现有 OpenSSH 连接。
- Compose 对 `hop-rs` 后端和 `hop-rs-frontend` 面板使用相同且匹配的 `HOP_VERSION` 标签；v0.2.5 面板镜像没有功能变化。

如需回滚，停止 Hop 并将 `HOP_VERSION=v0.2.4`，即可恢复上一组匹配的后端与面板镜像。由于 v0.2.5 没有迁移或持久化格式变更，现有数据库可以继续使用；如果同时改动过其他配置或数据，请按需恢复备份。

## 发布产物

容器部署请将匹配的镜像固定为 `v0.2.5`，不要使用 `latest`。升级前始终保留旧镜像标签和配置副本，以便在无网络时执行回滚。
