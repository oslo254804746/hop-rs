# Hop v0.2.8

[简体中文](v0.2.8.zh-CN.md) | **English**

Released 2026-08-27.

v0.2.8 is the closeout release for the current backend, official panel, and
OpenWrt distribution line. All three deliverables are paired at `v0.2.8`.
There is no SQLite migration or configuration-format change.

## Graceful shutdown

On SIGINT or SIGTERM, Hop stops accepting new Control API and SSH connections.
Active SSH transports receive a termination signal and are given up to five
seconds to drain. Connections that do not finish in that window are terminated
so a container or service restart does not leave the listener running.

## Session recovery

At startup, records left in `started` state by an earlier process are closed as
`failed` with the error `Hop server restarted before session completed`. The
recovery runs before the current process opens either listener, so newly
created sessions are not selected. Existing completed session records are
unchanged.

## Upgrade and rollback

- Back up `hop.yaml`, `hop.db`, `hop.secret`, and `hop_host_key` together.
- Set `HOP_VERSION=v0.2.8` and deploy the matching `hop-rs` backend and
  `hop-rs-frontend` panel images from Compose.
- Install the matching `v0.2.8` LuCI package/core bundle on OpenWrt; do not
  mix a backend, panel, or OpenWrt artifact from another version.
- After restart, check the panel status, one SSH connection, and the session
  history for recovered records.

To roll back, stop the deployment, restore the `v0.2.5` backend and panel, and
restore the previous `v0.2.4` OpenWrt package where applicable. This release
has no database migration, so the existing catalog can be reused; restore the
backup if other configuration or data changes must also be reverted.

## Release artifacts

Pin all three deliverables to `v0.2.8` rather than `latest`, and retain the
previous matching artifacts for an offline rollback.
