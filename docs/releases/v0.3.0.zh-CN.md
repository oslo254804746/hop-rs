# Hop v0.3.0

**简体中文** | [English](v0.3.0.md)

v0.3.0 将 Hop 演进为零目标端 Agent 的个人与多机（Multi-VPS）日常运维中枢：打通托管模式下的 `-L` / `-D` 端口转发与 Cursor / VS Code Remote-SSH 免密接入、支持 `via_asset` 跨内网链式多级跳板、实现 TUI 选机后的 SFTP 自动跟随与同生命周期回收、补齐新机一键洗密（Ed25519 公钥下发与密码轮换），并内置后台定时拨测、RTT 趋势火花线与 Telegram / Bark / Webhook 告警通知。`hop-rs`、`hop-rs-frontend` 与 `luci-app-hop` 三仓统一配对为 `v0.3.0`。

## 核心更新

- **托管模式端口转发（`-L` / `-D` / Cursor & VS Code Remote-SSH）**：使用托管 SSH 资产登录时（`ssh -L ... <asset>@<hop-host>`、`ssh -D ... <asset>@<hop-host>` 或 `~/.ssh/config` 的 `--mode relay`），客户端可直接通过 Hop 已完成保险库认证的目标 SSH 会话打开 `direct-tcpip` 转发通道，无需在本地存放目标机私钥或密码。支持全局 `ssh.allow_managed_tcp_forwarding`（默认 `true`）与单资产 `allow_tcp_forwarding`（默认 `true`）双重开关。
- **链式多级跳板（`via_asset`）**：SSH 与 TCP 资产均可指定上游托管 SSH 跳板资产（`hop.yaml` 的 `via_asset`、CLI `--via-asset`、面板与 API 的 `via_asset_id`），支持最多 4 跳级联、环路检测与逐跳 TOFU 主机指纹校验，无缝覆盖交互式 Shell、`exec`、SFTP、端口转发与协议拨测。
- **TUI 选机 SFTP 自动跟随与生命周期绑定（`hop@<hop-host>`）**：Netcatty、Xterminal、WindTerm、MobaXterm 等 GUI 终端通过 `ssh hop@<hop-host>` 进入 TUI 选机时（含菜单等待回车期间预开的 SFTP 通道），同连接多路复用或同公钥+同来源 IP 的并发 SFTP / `exec` / 转发通道会自动跟随接入所选目标机；一旦退出目标 Shell 返回 TUI 或断开主连接，所有跟随通道会立即同步关闭。
- **新机一键密钥洗密（`bootstrap-key`）**：提供零 Agent 原子化 5 步密钥纳管（`POST /api/v1/assets/{id}/bootstrap-key` 与 `hop-server asset bootstrap-key <target>`）：自动生成 Ed25519 密钥对、以严格 `0700`/`0600` 权限幂等写入 `authorized_keys`、发起全新第二次 SSH 连接验活新私钥、原子切换保险库凭据，并仅在公钥验活成功后按需关闭 `sshd` 密码登录。
- **后台定时拨测、RTT 火花线与多通道告警（Telegram / Bark / Webhook）**：内置定时拨测调度器（`GET/PUT /api/v1/probe/settings`、`GET /api/v1/assets/probe-history`），支持配置拨测间隔、超时、连续失败阈值与恢复通知，在面板资产列表渲染 RTT 延迟火花线，并支持主密钥加密存储的 **Telegram Bot**、**Bark（iOS 推送）** 与 **HMAC-SHA256 Webhook** 告警通道（`GET/POST/PUT/DELETE /api/v1/notifications/channels` 及 `/test` 一键测试推送）。
- **细粒度审计诊断与严格 CSP 收口**：拒绝访问或拒绝端口转发时在 `sessions.error` 与 `audit_events`（`session.access_denied`、`session.forward_denied`）记录精确原因；彻底移除前端行内样式以严格满足 `style-src 'self'` CSP 策略；`luci-app-hop` 同步放行全部 `v0.3.0` 新接口并保持包体积低于 256 KiB 门禁。

## 升级说明

- 现有 `v0.2.x` SQLite 数据库会在首次启动 `v0.3.0` 时通过事务自动完成增量表结构升级（补齐 `via_asset_id`、`allow_tcp_forwarding`、`asset_probe_samples`、`probe_settings` 与 `notification_channels`），原有资产、加密凭据、入口公钥与 Known Hosts 全部保留。
- 升级前请成对备份 `hop.yaml` 与 `data_dir`（`hop.db`、`hop.secret`、`hop_host_key`），随后将 `hop-rs`、`hop-rs-frontend` 与 `luci-app-hop` 同步升级至 `v0.3.0`。
