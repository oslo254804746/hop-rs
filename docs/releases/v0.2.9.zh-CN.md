# Hop v0.2.9

**简体中文** | [English](v0.2.9.md)

v0.2.9 围绕个人开发者、多机（Multi-VPS）运维及 Cursor / VS Code Remote-SSH 工作流完成 `v0.2` 线收口，`hop-rs`、`hop-rs-frontend` 与 `luci-app-hop` 三仓统一配对为 `v0.2.9`。

## 核心更新

- **零 Agent 按需协议与延迟探测（`asset_health`）**：全面盘活健康表，在 Catalog、Control API（`POST /api/v1/assets/probe`、`POST /api/v1/assets/{id}/probe`）、CLI（`hop-server asset probe`）、SSH TUI（`r` 键）与网页面板中展示连接状态与握手 RTT；SSH 探测直接校验目标端 RFC 4253 `SSH-` Banner，无需在目标机安装任何探针。
- **审计流水与周期清理（`audit_events`）**：统一记录 Control API 与本地 CLI 的资源变更与探测事件，提供 `GET /api/v1/audit-events` 与 `hop-server audit list`，并在启动时及运行期每 6 小时按 `session_retention_days` 自动清理。
- **多机与远程 IDE 体验重塑**：新增 `hop-server ssh-config`（支持 `relay` 免密直连与 `proxyjump` 端到端隧道两种模式），支持在 `hop.yaml` 中声明资产 `tags`，补齐本地资产 `display_name` 与 `--credential <名称或ID>`，并重构官方面板视觉与交互。
- **安全与协议收口**：收紧 `.hop` 代理端口精确校验，透传客户端真实 PTY `TERM`，补齐会话 `key_id`/`asset_id` 关联，移除未挂载的远程 HTTP Manifest 接口（`/api/v1/config/*`），并启用 `linux/amd64` + `linux/arm64` 双架构容器镜像构建。

## 升级说明

- 从 `v0.2.8` 升级无需 SQLite 迁移。
- 升级前请成对备份 `hop.yaml` 与 `data_dir`（`hop.db`、`hop.secret`、`hop_host_key`），随后将 `hop-rs`、`hop-rs-frontend` 与 `luci-app-hop` 同步升级至 `v0.2.9`。
