# Hop v0.1.6

**简体中文** | [English](v0.1.6.md)

发布于 2026-08-09。

v0.1.6 新增托管 SSH 远程命令，并为管理员提供安全、可审计的在线网关会话终止能力。相较 v0.1.5，本版本没有新增数据库迁移，也没有修改配置格式。

## 主要变化

### 托管远程命令

OpenSSH 现在可以通过用户名选定 SSH 资产并执行命令：

```bash
ssh -p 2222 web-prod-01@hop-host 'uname -a'
printf 'input' | ssh -p 2222 web-prod-01@hop-host cat
ssh -tt -p 2222 web-prod-01@hop-host 'sudo systemctl status app'
```

Hop 使用资产绑定的凭据连接目标，并转发 stdin、stdout、stderr、退出码、退出信号和可选 PTY。远程命令不会进入 TUI，也不会显示交互式 Hop banner。会话以 `exec` 模式记录；命令内容有意不写入会话审计。

在命令抵达目标之前，Hop 会执行与交互式 SSH、SFTP、ProxyJump 和 TCP 转发相同的稳定 Key-to-Asset 授权校验。远程命令需要一项具有可用托管凭据的 SSH 资产。

### 在线会话控制

Admin Web 的审计日志页会标识当前由网关登记的连接。Owner 和 Operator 可以终止单个在线连接或全部在线连接；Viewer 保持只读可见。

终止能力覆盖 TUI、托管交互式 SSH、托管远程命令、SFTP、直连 SSH、ProxyJump 和通用 TCP 中继。会话最终状态为 `terminated`，管理员操作会把操作者、来源、目标、结果和安全元数据写入审计日志。

### 保留健康统计

托管 SSH 和直连 TCP 的连接尝试仍会更新真实资产健康状态与延迟数据。新增终止处理不会覆盖这些成功和失败信号。

## 兼容性与升级

- v0.1.6 不新增 SQLite 迁移。
- 不新增或删除配置项。
- 现有资产、凭据、SSH 授权密钥、Known Hosts、审计事件和会话都会保留。
- 从 v0.1.5 仅升级二进制到 v0.1.6 后可以回滚，但每次升级前仍建议执行停服备份。

应将 Hop 视为访问关键基础设施：先准备备用管理路径，下载并校验产物，停止 Hop，备份持久化数据与配置，安装 v0.1.6，最后验证 Admin 登录和一条真实 SSH 路径。具体命令见 [Deployment Upgrade Runbook](../deployment.md#upgrade)。

## 发布产物

GitHub Release 提供：

- `hop-server-linux-amd64`
- `hop-server-linux-amd64.sha256`
- `hop-admin-web-static.tar.gz`
- `hop-admin-web-static.tar.gz.sha256`

安装前使用匹配的 `.sha256` 文件校验下载产物。容器部署固定使用 `ghcr.io/oslo254804746/hop-rs:v0.1.6`，不要在生产环境使用浮动标签。

## 已知限制

- 在线会话登记只存在于当前进程，Hop 不会聚合多个网关实例的会话。
- 终止会话会立即生效，不会向已连接的 SSH 客户端二次确认。
- 命令内容不会保留用于回放或审计导出。
- Admin 仅支持本地密码，尚无 OIDC。
- 审计筛选、分页、导出和留存设置仍属于后续工作。
