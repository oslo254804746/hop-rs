# Hop v0.3.1

**简体中文** | [English](v0.3.1.md)

发布于 2026-11-20。

`v0.3.1` 是针对交互式 SSH TUI（`ssh hop@<hop-host>`）的体验优化与渲染修复版本。不包含 SQLite 表结构或配置文件格式变更，现有 `v0.3.0` 网页面板（`hop-rs-frontend:v0.3.0`）与 `luci-app-hop` 可直接兼容使用。

## 更新内容

- **TUI 即时刷新列表（`f`、`Ctrl+R`、`F5`）**：在已打开的交互式 SSH TUI 中可直接从本地 Catalog 重新加载当前公钥授权的最新资产列表，无需退出重连或等待全量网络拨测，并按资产 ID 保持当前光标选中的机器不偏移。
- **分组标题行高感知与平滑滚动**：计算列表可见窗口与滚动偏移时完整计入分组标题行高，彻底消除视口底部孤儿分组标题（例如 30 行终端下底部单独露出空的 `untagged` 标题而下方机器无法滚出的问题），准确展示 `当前/总数` 滚动指示，并在长分组内部滚动时保留顶部分组标题。
- **分组排序与状态提示细节**：忽略纯空白标签并将 `untagged` 分组固定排在全部命名标签之后；对无托管凭据资产按回车时改为状态栏提示，不再向备用屏幕裸写字符破坏排版。

## 升级方式

- **Docker Compose**：拉取 `hop-rs:v0.3.1` 并重启（`docker compose pull && docker compose up -d`）；仓库 `compose.yaml` 默认将 `hop-rs:v0.3.1` 与已发布的 `hop-rs-frontend:v0.3.0` 配对。
- **OpenWrt / 静态二进制**：将 `hop-server` 更新至 `v0.3.1`（`core_version` 为 `latest` 或 `v0.3.1` 时执行 `/usr/share/hop/hop-core install`）并重启 `hop` 服务即可。
