# Hop v0.2.8

**简体中文** | [English](v0.2.8.md)

发布于 2026-08-27。

v0.2.8 是当前后端、官方面板和 OpenWrt 分发线的收口版本，三端统一配对
为 `v0.2.8`。不包含 SQLite 迁移或配置格式变更。

## 优雅关闭

收到 SIGINT 或 SIGTERM 后，Hop 会停止接受新的 Control API 和 SSH 连接。
活动 SSH 传输会收到终止通知，并获得最多 5 秒排空时间；超时仍未退出的
连接会被终止，避免容器或系统服务重启后监听器继续运行。

## 会话恢复

启动时，上一个进程遗留的 `started` 会话会被关闭并标记为 `failed`，错误为
`Hop server restarted before session completed`。恢复发生在当前进程打开任一
监听器之前，因此不会选中当前进程新建的会话；已完成的历史记录不变。

## 升级与回滚

- 将 `hop.yaml`、`hop.db`、`hop.secret` 和 `hop_host_key` 一起备份。
- 设置 `HOP_VERSION=v0.2.8`，通过 Compose 部署匹配的 `hop-rs` 后端与
  `hop-rs-frontend` 面板镜像。
- 在 OpenWrt 安装匹配的 `v0.2.8` LuCI 软件包/核心 bundle；后端、面板和
  OpenWrt 产物不要混用不同版本。
- 重启后检查面板状态、一次 SSH 连接，以及会话历史中是否存在恢复记录。

如需回滚，停止部署并恢复 `v0.2.5` 后端与面板；使用 OpenWrt 时恢复此前的
`v0.2.4` 软件包。本版本没有数据库迁移，可以继续使用现有 Catalog；如果同时
改动了其他配置或数据，请恢复备份。

## 发布产物

三端均固定使用 `v0.2.8`，不要使用 `latest`，并保留上一组匹配产物以便离线
回滚。
