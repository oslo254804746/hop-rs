# Hop v0.3.1

[简体中文](v0.3.1.zh-CN.md) | **English**

Released 2026-11-20.

`v0.3.1` is a focused quality-of-life and rendering fix release for the interactive SSH TUI (`ssh hop@<hop-host>`). There are no SQLite schema or configuration-format changes, and existing `v0.3.0` Web Panel (`hop-rs-frontend:v0.3.0`) and `luci-app-hop` deployments remain directly compatible.

## Highlights

- **Instant TUI Catalog Refresh (`f`, `Ctrl+R`, `F5`)**: Reloads authorized assets directly from the SQLite Catalog inside an active SSH TUI session without disconnecting or waiting for network RTT probes, while keeping the currently highlighted asset selected by ID.
- **Group-Aware Viewport & Scrolling**: Accounts for 1-line tag group headers alongside 2-line asset rows when computing scroll offsets and viewport bounds. Eliminates trailing orphan group headers (such as an empty-looking `untagged` row at the bottom of a 30-row terminal), shows the `selected/total` indicator whenever group headers push items past the viewport, and keeps the active group heading visible while scrolling through large groups.
- **Tag & Notice Polish**: Places the `untagged` group consistently after all named tag groups, ignores whitespace-only tags, and renders missing-credential connect hints cleanly in the TUI status bar rather than writing raw lines over the alternate screen.

## Upgrade

- **Docker Compose**: Pull the updated `hop-rs:v0.3.1` image (`docker compose pull && docker compose up -d`); `compose.yaml` pairs `hop-rs:v0.3.1` with `hop-rs-frontend:v0.3.0` out of the box.
- **OpenWrt / Static Binary**: Update `hop-server` to `v0.3.1` (`hop-core install` when `core_version` is `latest` or `v0.3.1`) and restart the `hop` service.
